# React Modeler Example

1. Clone `camunda-web-modeler` repository
    ```shell
    git clone git@github.com:Miragon/camunda-web-modeler.git
    ```

2. Install dependencies
    ```shell
    # cd camunda-web-modeler
    yarn install
    ```
   
3. Build the project
    ```shell
    # cd camunda-web-modeler
    yarn build
    ```
   
4. Create a link to `camunda-web-modeler` repository
    ```shell
    # cd camunda-web-modeler
    yarn link
    ```
   
5. Link `camunda-web-modeler` to this repository
    ```shell
    # cd vite-react-modeler
    yarn link @miragon/camunda-web-modeler
    ```

6. Install dependencies
    ```bash
    # cd vite-react-modeler
    yarn install
    ```
   
7. Start the development server
    ```bash
    # cd vite-react-modeler
    yarn dev
    ```
